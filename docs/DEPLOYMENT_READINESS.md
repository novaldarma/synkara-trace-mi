The Booklet does not publish numeric weights for its criteria. No ranking is guaranteed.

## 2. Local run and protected AI endpoint

Install Node 24+, run `npm ci`, copy `.env.example` to `.env.local`, then fill only the project's publishable Supabase URL and key. Run `npm run check:config`, `npm run dev`, and sign in using the authorized demo account. To use live model-generated retrospective wording, set `TRACE_AI_PROVIDER=fireworks`, `FIREWORKS_API_KEY`, and `FIREWORKS_MODEL` in `.env.local` and restart `npm run dev`. Gemini may remain configured only as an optional provider. The same API handler runs locally and on Vercel. Without a model key it returns a labeled source-bound summary; replay intentionally stays deterministic. Keep `.env.local` out of ZIP and git. Never post a provider secret in a chat, `VITE_PUBLIC_` variable, or browser field.

The local `/api/assistant` rejects missing bearer tokens, calls Supabase Auth to validate the JWT, checks active membership, reads source rows under that caller's RLS, and returns bounded facts plus clickable original row/column links. A generated answer remains a draft. Inspect it against its verified facts and never portray a weekly ALARM as a confirmed cause or a recommended physical repair.
